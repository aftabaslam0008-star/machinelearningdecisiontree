TASK 1: TITANIC SURVIVAL PREDICTION
Objective:
Build a Decision Tree Classifier to predict whether a passenger survived.

Features used:
Pclass, Sex, Age, SibSp, Parch, Fare, Embarked

Target:
Survived

Steps:
1. Load Titanic train.csv.
2. Select relevant features.
3. Handle missing values.
4. Convert categorical values into numbers.
5. Split data into training and testing sets.
6. Train Decision Tree Classifier.
7. Predict test data.
8. Calculate accuracy.
9. Display classification report and confusion matrix.
10. Visualize the decision tree.

CONCLUSION:
Decision Tree is a supervised learning algorithm that uses decision rules to classify data.
The tree contains a root node, decision nodes, branches and leaf nodes.
Using max_depth helps reduce overfitting and makes the tree easier to understand.
